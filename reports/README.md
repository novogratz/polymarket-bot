# Generated Reports

This directory is reserved for sanitized, reproducible research outputs. Customer-specific reports, wallet identifiers, raw production logs, and local performance exports must remain outside version control.

Before committing a report:

1. Document the generating command and data period.
2. Remove credentials, wallet identifiers, and customer information.
3. Distinguish observed data from interpretation.
4. State limitations and avoid claims of guaranteed profitability.
5. Confirm that the source data may be redistributed.

Operational results belong under the ignored `data/` directory.
